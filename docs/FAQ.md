# Frequently Asked Questions (FAQ)

### General

**Q: I registered but I cannot log in. It says "Account Pending".**
A: All student and staff registrations must be verified by the ICT Admin to prevent spam and ensure you belong to the university. This usually takes less than 24 hours.

**Q: Can I use my personal Gmail address to register?**
A: No. The system strictly requires an official `@university.edu.ng` email address for security and verification purposes.

### Submitting Tickets

**Q: What Priority should I select?**
A: 
- **Low:** Software requests, generic inquiries.
- **Medium:** Single computer issues, minor printer faults.
- **High:** Entire lab offline, faculty internet down.
- **Critical:** Exam server down, portal completely offline. Do not abuse this level.

**Q: Can I attach a screenshot of the error?**
A: File attachment support is available based on Firebase Storage limits (max 5MB, PNG/JPG). Attachments can be added via comments once the ticket is created.

### Tech Support

**Q: Why was my ticket closed?**
A: A technician marks a ticket "Resolved" when they believe they have fixed the issue. If you do not reply or reopen the ticket within 7 days, the system automatically transitions it to "Closed."

**Q: Is there an app I can download?**
A: The Helpdesk is a Progressive Web App (PWA). You can open it in your mobile browser (Chrome/Safari) and select "Add to Home Screen" to install it like a native app. Push notifications will work natively on Android devices.
